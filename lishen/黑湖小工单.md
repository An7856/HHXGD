# 黑湖小工单旗舰版（含委外管理）从0到1完整操作手册

> **适用版本**：黑湖小工单旗舰版（含销售管理、采购管理、委外管理）
> **工厂类型**：TPE/TPR软胶解压玩具（捏捏乐+电子配件）生产工厂
> **产品案例**：彩虹捏捏乐（红/黄/蓝三色混装，内置电子配件，5000套，美国客户外贸订单）
> **核心模式**：**报工即扣料**——工人报工提交良品数量的那一刻，系统自动完成产量统计、物料库存自动扣减、计件工资自动累积，无需人工干预
> **订单履约链路**：销售订单 → 履约助手（安排生产 + 生成采购需求 + 安排采购） → 采购到货入库 → 工单自动拆解 → 委外工序管控 → 生产执行 → 销售发货
> **目标读者**：从0到1上线


## ⚠️ 特别说明：关于工单自动拆解机制


**黑湖小工单的多级BOM工单拆解，不是在销售订单页面点击“生成工单”完成的，而是通过“履约助手→安排生产”触发的。**

| 操作方式 | 生成结果 | 正确性 |
|----------|----------|--------|
| 销售明细→生成工单 | **只生成1张成品工单**，不展开BOM | ❌ 不适用于多级BOM产品 |
| **履约助手→安排生产** | **自动展开BOM所有层级，生成全部工单（10张）** | ✅ **正确操作** |

> 💡 **为什么只出了1张工单？** 因为你点的是销售明细里的“生成工单”，那个按钮只生成当前产品的工单。要展开多级BOM，必须走“履约助手→安排生产”这条路径。


## 第一部分：系统认知与核心逻辑

### 一、系统核心逻辑：从订单到交付的完整闭环

黑湖小工单旗舰版围绕 **“订单履约”** 这条主线运行，把销售、采购、委外、生产、仓储五个环节协同在同一套数据上。完整业务闭环如下：

1. **销售接单**：创建销售订单并审批
2. **履约助手协同**：
   - **安排生产**：系统根据BOM自动展开所有层级，一键生成全部工单
   - **生成采购需求**：系统根据BOM和库存自动计算缺料，生成采购建议
   - **安排采购**：选中采购需求，一键合并生成采购订单
3. **采购到货入库**：原料到货后扫码入库，库存自动更新
4. **委外工序管理**：工单执行到委外工序时，自动生成委外需求
5. **生产执行**：内部工序报工 → 委外出库发料 → 外协加工反馈 → 委外入库
6. **发货交付**：成品入库 → 销售出库 → 订单完结

**报工即完成一切**：工人提交良品数量的那一刻，系统同时完成产量统计、物料库存自动扣减、计件工资自动累积。报工联动库存的核心价值在于：**生产消耗与库存变化在同一时刻发生，中间没有时间差留给误差**。

### 二、履约助手三大核心功能

| 功能按钮 | 作用 | 触发时机 |
|----------|------|----------|
| **安排生产** | 系统根据BOM自动展开所有层级，一键生成全部半成品和成品工单 | 销售订单审批后 |
| **生成采购需求** | 系统根据BOM和当前库存自动计算缺料，生成采购建议清单 | 安排生产后，或库存不足时 |
| **安排采购** | 选中采购需求，合并生成采购订单，自动带出默认供应商和单价 | 采购需求确认后 |

## ⚠️ 配置前必读：核心规则

### 规则一：产品的“工艺路线”字段，什么时候填、什么时候不填？

| 产品类型 | 工艺路线是否填写 | 原因 |
|----------|-----------------|------|
| **原材料（外购）** | ❌ **不填，保持空白** | 买回来的，不需要生产 |
| **半成品（自制）** | ✅ **必须填** | 生产出来的，系统需要知道怎么做 |
| **成品（自制）** | ✅ **必须填** | 系统需要知道成品经过哪些工序才能入库 |

### 规则二：外协工序需在工序设置中标记“委外”

将“喷漆”等需要外包的工序**标记为委外工序**，工单执行到该工序时可一键生成委外单。

### 规则三：产品属性决定采购需求

| 产品属性 | 采购模块行为 |
|----------|-------------|
| **外购**（原材料、包材） | 系统在“生成采购需求”时会**自动计算**这些物料的需求量 |
| **自制**（半成品、成品） | 系统**不会**生成采购需求，而是生成生产工单 |

### 步骤五：创建不良品项

进入「基础数据」→「不良品项」→「创建不良品项」：

- **注塑不良**：缩水、飞边、缺胶、色差、配比错误
- **灌粉不良**：克重不准（偏离3g）、漏粉
- **装电子配件不良**：配件装反、线路脱落
- **粘盖不良**：胶水溢出、盖子歪斜
- **移印/喷漆不良**：偏位、流油、颗粒、划伤
- **填充不良**：克重不准（偏离45g）、漏液
- **包装不良**：吸塑破损、彩盒折痕、装箱错误
- **委外不良**：工废（外协责任）、料废（我方责任）

## 第三部分：自定义字段配置

自定义字段是旗舰版的核心能力，支持在工单、报工、工序、产品、BOM、采购单、出入库、委外、客户、供应商、设备等模块添加自定义字段。

### 一、操作步骤

1. 进入「系统配置」→「自定义字段」
2. 选择要加字段的模块
3. 点击「新增字段」，填写字段名称，选择字段类型（文本/数字/日期/下拉/附件等）
4. 设置是否必填、默认值等
5. 保存

### 二、针对工厂的推荐自定义字段

| 模块 | 建议添加的字段 | 字段类型 | 用途 |
|------|----------------|----------|------|
| 注塑工序 | 设备编号、模温、射胶压力 | 数字/文本 | 工艺参数追溯 |
| 灌粉工序 | 粉料克重（标准3g） | 数字 | 记录每件灌粉克重 |
| 填充工序 | 麦芽糖浆克重（标准45g） | 数字 | 记录每件填充克重 |
| 委外工序 | 外协批次号、加工费单价 | 文本/数字 | 委外追溯与对账 |
| 采购订单 | 采购批次号、预计到货日期 | 文本/日期 | 采购追踪 |
| 工单 | 客户订单号、色号、包装要求 | 文本/附件 | 订单信息追溯 |


## 第四部分：跑通第一个完整订单

> 📦 **订单**：美国客户“ABC Toys”，5000套“彩虹捏捏乐”（红/黄/蓝三色混装，内置电子配件），喷漆工序外包给“宏达喷漆厂”。

### 一、完整操作流程

#### 第一步：创建销售订单

1. 进入「销售管理」→「销售订单」→「创建销售订单」
2. 选择客户“ABC Toys”，填写合同编号
3. 选择产品“FIN-RAINBOW（捏捏乐-三色套装）”，数量5000套
4. 提交订单后点击「审批」确认

#### 第二步：履约助手 → 安排生产（⚠️ 关键！工单拆解的正确路径）

1. 进入「销售管理」→「履约助手」
2. 找到该订单，点击「安排生产」——系统根据BOM展开所有层级，自动生成全部10张工单（6张注塑+3张组装含委外喷漆+1张成品包装）

> ⚠️ **只生成1张工单的根本原因**：必须走“履约助手→安排生产”，而不是在销售明细里点“生成工单”。前者会展开BOM所有层级，后者只生成当前产品的工单。

#### 第三步：生成采购需求 → 安排采购

1. 在「履约助手」中勾选该订单行，点击「生成采购需求」
2. 系统自动计算缺料，生成采购建议清单（显示缺什么、缺多少、什么时候要用）
3. 选中需要采购的物料，点击「安排采购」，系统自动带出默认供应商和单价
4. 确认后生成采购订单

#### 第四步：采购到货入库

1. 原料到货后，进入「采购管理」→「采购收货」
2. 手机扫码物料条码，录入实收数量、批次号（支持部分到货）
3. 提交后，系统自动增加原料库存，同步更新工单物料状态

#### 第五步：内部工序报工（到委外工序前）

1. 注塑（含拌料）报工 → 系统自动扣SEBS7561+白油+色粉 → 皮和盖子自动入库
2. 灌粉报工 → 系统自动扣填充粉料（3g/个）
3. 装电子配件报工 → 系统自动扣电子配件（1个/套）
4. 粘盖子报工 → 系统自动扣皮+盖（各1个/套）
5. 移印报工 → 记录产量，不扣物料

#### 第六步：委外管理（喷漆工序）

**6.1 创建委外加工单**

1. 工单执行到“喷漆”工序时，进入工单详情页，找到“喷漆”工序
2. 点击「生成委外单」，选择外协供应商“宏达喷漆厂”
3. 填写委外加工数量、计划回货日期、单件加工费
4. 系统自动带出本工序所需物料，提交生成委外单

**6.2 委外出库发料**

1. 打开工单详情，找到委外工序“喷漆”，点击「委外出库」
2. 系统自动带出BOM所需的半成品，填写本次外发数量
3. 保存生成委外出库单，**库存自动扣减**，打印《委外发料单》随货
4. 把委外单据二维码/微信链接发给外协厂

**6.3 外协厂协同加工**

外协厂通过微信链接查看任务：
1. 查看加工要求、图纸、发料明细
2. 加工完成后，点击「完工/发货」，填写良品数、不良数、原因
3. 上传不良品照片作为证据

**6.4 委外入库收货**

1. 进入「委外管理」→「委外入库」
2. 找到对应委外单，点击「收货」
3. 录入实收良品（入半成品仓）、不良品（区分工废/料废）
4. 提交后，**系统自动增加半成品库存**，委外工序自动标记完成

#### 第七步：继续后续工序

1. 填充报工 → 自动扣麦芽糖浆（45g/个）→ 各颜色完成品入库
2. 吸塑报工 → 自动扣吸塑内托
3. 装PET报工 → 自动扣PET展示盒
4. 入彩盒报工 → 自动扣彩盒
5. **入箱报工** → 自动扣外箱+红/黄/蓝完成品 → **成品自动入库** ⭐

> 💡 **成品入库触发点**：成品“三色套装”的投料工序设置为“入箱”，所以只有“入箱”报工时才会触发成品自动入库。

#### 第八步：销售发货交付

1. 进入「销售管理」→「销售订单」，找到要发货的订单
2. 订单详情页点击「销售出库」，自动带出订单产品明细
3. 填写本次发货数量、批次、仓库、快递公司、快递单号
4. 保存并确认出库，系统自动扣减成品库存
5. 订单状态更新为「部分发货/全部发完」，可打印出库单随货给客户

**手机端扫码发货**：打开APP进入「出库」，扫描销售订单二维码/成品条码，核对数量后确认出库，一键完成。

> 💡 **分批发货**：一张销售订单可多次出库，系统自动统计已发/未发数量。

## 第六部分：库存管理模块操作

旗舰版的库存管理是“生产联动型”的，不是事后补录。入库、出库、库存变动都由生产动作自动驱动。

### 一、库存管理模块完整菜单

| 菜单名称 | 功能说明 |
|----------|----------|
| **入库单** | 采购入库、生产完工入库、委外入库、其他入库 |
| **出库单** | 工单领料出库、委外出库、销售出库、其他出库 |
| **调整单** | 期初调整、盘盈盘亏、报废调整 |
| **调拨单** | 仓库间物料转移 |
| **库存报表** | 库存收发明细、库存余额、进销存汇总 |
| **多维库存明细** | 按仓库、批次、物料多维度查看库存 |

### 二、库存与生产/采购的联动机制

| 触发动作 | 系统自动完成的库存变化 |
|----------|----------------------|
| **采购收货** | 原料库存自动增加 |
| **工单报工** | 物料库存自动扣减（报工联动扣料） |
| **注塑报工** | 半成品库存自动增加 |
| **入箱报工** | 成品库存自动增加 |
| **销售出库** | 成品库存自动扣减 |
| **委外出库** | 库存扣减，生成“委外在制库存” |
| **委外入库** | 半成品/成品库存自动增加 |

> 💡 **核心原则**：库存不需要单独操作，报工/入库动作自动联动库存。工人报工提交良品数量的那一刻，库存就变了。

### 三、库存预警

系统支持为关键物料设置安全库存上下限。当物料库存低于下限时，自动触发补货提醒，避免缺料导致生产停滞；当库存超过上限时，提示积压风险。


## 第七部分：采购管理模块操作

采购模块解决的核心问题是采购计划与生产计划脱节：备料靠经验判断，物料要么早到积压资金，要么晚到拖停产线。

### 一、采购管理模块完整菜单

| 菜单名称 | 功能说明 |
|----------|----------|
| **采购需求** | 系统根据BOM和库存自动生成的缺料采购建议 |
| **采购订单** | 所有采购订单列表 |
| **采购明细** | 采购订单详细执行情况 |
| **采购收货** | 到货扫码入库操作入口 |
| **采购退货** | 不良品/错料退货操作入口 |
| **智能补货** | 系统根据库存水位自动建议补货 |

### 二、采购完整操作流程

**1. 生成采购需求**：在「履约助手」中点击「生成采购需求」，系统根据BOM计算原料用量，核对当前库存，自动生成采购建议清单。

**2. 安排采购**：勾选需要采购的物料，点击「安排采购」，系统自动带出默认供应商和单价，合并生成采购订单。

**3. 采购收货**：进入「采购管理」→「采购收货」，扫码物料条码，录入实收数量（支持部分到货），系统自动增加原料库存。

**4. 采购退货**：进入「采购管理」→「采购退货」，在原采购订单中操作退货，系统自动扣减库存并生成退货记录。

> 💡 **部分到货处理**：每次收货时修改数量即可，系统自动记录已到货量和缺货量。

## 第九部分：全局关键注意事项（必读）

### 一、工单生成的正确操作路径（关键！）

| 操作方式 | 结果 | 正确性 |
|----------|------|--------|
| 销售明细→生成工单 | 只生成1张成品工单 | ❌ 不适用于多级BOM |
| **履约助手→安排生产** | **自动展开BOM，生成全部10张工单** | ✅ **正确操作** |

### 二、工艺路线填写规则

| 产品类型 | 工艺路线 | 后果 |
|----------|----------|------|
| **原材料（外购）** | **不填，保持空白** | 如果填了，系统会误以为要生产 |
| **半成品/成品（自制）** | **必须填** | 如果不填，生成工单时会漏掉 |

### 三、成品入库触发点

**成品“三色套装”的投料工序必须设置为“入箱”** ，不能设置为更早的工序。只有装入外箱后，产品才算真正完成。

### 四、委外工废与料废区分

- **工废**（外协责任）：不计加工费，可向供应商索赔
- **料废**（我方责任）：正常计价，我方承担损失

### 五、报工联动库存的前提

BOM用量标准必须准确。起步时先从用料金额大、结构相对简单的产品做起，边用边校准。

## 第十一部分：常见问题

**Q：为什么销售订单只生成了1张工单而不是10张？**
A：因为你点的是“销售明细→生成工单”。要实现多级BOM自动拆解，必须走“履约助手→安排生产”路径。

**Q：采购需求是怎么生成的？**
A：在「履约助手」中点击「生成采购需求」，系统根据BOM计算原料用量，核对当前库存，自动生成采购建议清单。

**Q：外协厂需要安装软件吗？**
A：不需要。外协厂通过微信小程序链接即可查看任务、反馈完工，无需安装任何APP。

**Q：报工联动库存的触发条件是什么？**
A：BOM用量标准必须准确，且投料工序配置正确。工人提交报工的那一刻，系统自动按BOM折算物料消耗并更新库存。

**Q：入箱报工和成品入库的关系是什么？**
A：成品“三色套装”的投料工序设置为“入箱”，所以只有“入箱”报工才会触发成品自动入库。如果设置成更早的工序，产品还没装完箱就被当成成品了。
