### 2.3 设计评审Checklist

- [ ] **造型可行性**：无倒扣结构，或倒扣已设计滑块/斜顶方案
- [ ] **壁厚均匀性**：最大壁厚/最小壁厚 ≤ 2:1（PU材质）或 ≤ 1.5:1（TPR材质）
- [ ] **脱模可行性**：所有外观面拔模斜度≥1°（光面）/≥2°（纹理面）
- [ ] **结构强度**：悬伸结构（耳朵/尾巴/角）根部厚度≥2.5mm 或已设计加强筋
- [ ] **圆角处理**：所有尖角/锐边已改为圆角，R≥0.5mm（外观面R≥1.0mm）
- [ ] **分模线位置**：已避开正面/面部/主要视觉面，位于隐蔽处或设计为造型线
- [ ] **功能验证**：如有填充物，已设计防漏结构；如有挂绳，已设计牢固挂点
- [ ] **IP合规**：所有使用元素均在授权范围内，无侵权风险

## 四、完整打样流程（8阶段细化执行版）

> **RACI说明**：R=执行（Responsible）、A=负责（Accountable）、C=咨询（Consulted）、I=知会（Informed）

#### 1.2 DFM红线检查项（强制通过项）

| 检查项 | 标准 | 检查方法 | 不合格处理 |
|--------|------|----------|------------|

| 悬伸结构强度 | 耳朵/尾巴/角根部厚度≥2.5mm 或已设计加强筋 | 壁厚分析工具 | 增加根部厚度或加强筋 |

### Stage 2：手板/原型制作（5-10个工作日）

#### 2.1 工艺路线决策树

```
是否有手感参考样需求？
├── 是 → 需要真实材料手感？
```

#### 7.3 产前样评审决策点

```
产前样评审会议
├── 通过 → 签署《产前样确认书》（PP Sample Approval），下达大货订单
├── 有条件通过 → 列出整改项（≤3项），工厂整改后提交照片/报告确认，无需重新做样
└── 不通过 → 分析原因，返回对应Stage重新执行
    ├── 材料批次问题 → 返回Stage 4，更换材料批次
    ├── 模具问题 → 返回Stage 3，修模后重新T2
    ├── 工艺参数问题 → 返回Stage 4，重新定型参数
    └── 设计问题 → 返回Stage 1，设计变更
```

### Stage 8：大货量产 & 出货检验

#### 8.1 量产过程质量控制（IPQC体系）

| 节点 | 控制内容 | 频率 | 样本量 | 记录文档 | 异常处理 |
|------|----------|------|--------|----------|----------|
| **来料检验（IQC）** | 原料批次、颜色、硬度、气味、COA核对 | 每批次原料 | 按AQL抽样 | 《来料检验报告》 | 不合格批次退货或特采审批 |
| **首件检验（FAI）** | 每班首件全尺寸、全功能、全外观 | 每班/每模更换 | 全检首件 | 《首件检验报告》 | 不合格禁止开机，调整至合格 |
| **过程巡检（IPQC）** | 外观、尺寸、手感、重量、关键工艺参数 | 每小时/每50模 | 5pcs/次 | 《巡检记录表》 | 超差时停机调整，追溯已生产产品 |
| **半成品检验** | 修边、喷漆、印刷、植绒等工序质量 | 每工序/每小时 | 5pcs/次 | 《工序流转卡》 | 不合格品隔离，返工或报废 |
| **成品检验（FQC）** | 全外观、功能、包装、标签 | 全检或AQL抽样 | 按AQL标准 | 《成品检验报告》 | 不合格批次返工或特采审批 |
| **可靠性抽检** | 压缩循环、气味、附着力、跌落 | 每批次/每5000pcs | 3pcs/项 | 《可靠性测试报告》 | 不合格批次隔离，分析原因 |
| **包装检验** | 包装完整性、条码可读性、标签正确性 | 每批次 | 10箱/批次 | 《包装检验报告》 | 不合格返工包装 |

#### 8.2 AQL抽样标准应用指南

| 检验级别 | 严重缺陷（Critical） | 主要缺陷（Major） | 轻微缺陷（Minor） | 适用场景 | 抽样方案 |
|----------|----------------------|-------------------|-------------------|----------|----------|
| **全检** | 0 | 0 | 0 | 高价值礼品、首单、客诉后批次、返工批次 | 100%检验 |
| **AQL 1.0** | 0收1退 | 1.0 | 2.5 | 常规电商订单、品牌标准品 | GB/T 2828.1，一般检验水平II |
| **AQL 2.5** | 0收1退 | 2.5 | 4.0 | 低价促销品、大批量返单、基础款 | GB/T 2828.1，一般检验水平II |
| **AQL 4.0** | 0收1退 | 4.0 | 6.5 | 极低价值赠品、一次性活动物料 | GB/T 2828.1，一般检验水平I |

> **缺陷定义**：
> - **严重缺陷（Critical）**：涉及安全、法规、功能失效（如小零件脱落、重金属超标、锐利边缘）
> - **主要缺陷（Major）**：影响使用或销售（如明显色差、尺寸超差、印刷错误、明显污渍）
> - **轻微缺陷（Minor）**：不影响使用，轻微影响美观（如轻微划痕、轻微色差、包装轻微褶皱）

#### 8.3 出货检验（OQC / 第三方验货）

| 检验类型 | 执行方 | 抽样标准 | 检验内容 | 输出物 |
|----------|--------|----------|----------|--------|
| **工厂OQC** | 工厂质检部 | AQL标准 | 外观、尺寸、功能、包装、随机可靠性 | 《出厂检验报告》（COA） |
| **客户驻厂检验** | 品牌方品控 | AQL 1.0或全检 | 全项检验 | 《驻厂检验日报》 |
| **第三方验货（SGS/ITS/BV等）** | 第三方机构 | 按客户要求（通常AQL 1.0） | 外观、尺寸、功能、包装、开箱检查 | 《验货报告》 |
| **客户抽检** | 品牌方收货后 | 按收货标准 | 外观、功能、包装 | 《来料检验报告》 |

### 附录D：常用计算公式与工具

#### D1：模具腔数计算
```
腔数 = 首单量 ÷ (日产能需求 × 模具寿命周期内生产天数)

示例：首单量 = 10,000pcs，要求15天交货，每天工作20小时
日产能需求 = 10,000 ÷ 15 ≈ 667pcs/天
单腔周期 = 2分钟/模 → 单腔日产能 = 20×60÷2 = 600pcs/天
建议腔数 = 667 ÷ 600 ≈ 1.1 → 选择2腔模（预留20%缓冲）
```

#### D2：回弹时间测试方法（标准化）
```
1. 将样品置于标准环境（23±2°C，50±5%RH）中调节24小时
2. 使用标准压块（直径50mm，重量500g）或手指挤压至原高度50%
3. 释放同时启动秒表
4. 记录恢复至原高度90%所需时间（秒）
5. 每个样品测试3次，取平均值
6. 报告：平均值 ± 标准差，CV（变异系数）= 标准差/平均值 × 100%
```

#### D3：色差ΔE判定标准
```
ΔE < 1.0：人眼几乎无法分辨（优秀）
1.0 ≤ ΔE < 1.5：人眼轻微可辨，可接受（合格）
1.5 ≤ ΔE < 3.0：人眼可辨，需评估（有条件合格）
ΔE ≥ 3.0：明显色差，不合格
```

#### D4：CPK计算（过程能力指数）
```
CPK = min[(USL - μ) / (3σ), (μ - LSL) / (3σ)]
其中：USL=规格上限，LSL=规格下限，μ=平均值，σ=标准差

判定：
CPK ≥ 1.67：优秀，过程能力过剩
1.33 ≤ CPK < 1.67：合格，过程能力充足
1.00 ≤ CPK < 1.33：警告，过程能力不足，需改进
CPK < 1.00：不合格，过程能力严重不足
```
